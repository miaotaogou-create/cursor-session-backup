# 源码模块

| 模块 | 职责 |
|------|------|
| `paths.py` | 本机路径与备份目录命名 |
| `cursor_install.py` | 安装目录 / 版本探测 |
| `process_check.py` | 检测 / 关闭 / 启动 Cursor |
| `backup_index.py` | 历史备份列表与删除 |
| `sizing.py` | 体积估算与格式化 |
| `transfer.py` | robocopy / 文件拷贝与 OLD_* 挪移 |
| `backup.py` | 备份计划与执行 |
| `restore.py` | 恢复校验与执行 |
| `gui_app.py` | tkinter 界面 |
